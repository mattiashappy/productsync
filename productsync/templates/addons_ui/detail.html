Heads up: "WooCommerce" is a top-level menu item in WP-admin's left sidebar (look for the shopping-bag icon). It's not under WordPress's own "Settings" menu.
Step-by-step: generate your WooCommerce keys
  1. In WP-admin's left sidebar, click WooCommerce (shopping-bag icon, top-level item — not WP's "Settings").
  2. Inside the WooCommerce section, click Settings.
  3. At the top of the Settings page, click the Advanced tab.
  4. In the Advanced page's sub-links, click REST API.
  5. Click Add key. Description: ProductSync. Permissions: Read/Write. Click Generate API key.
  6. Copy the Consumer key (starts with ck_) and Consumer secret (starts with cs_) — they're shown only once.
  7. Paste both into the form below and click Connect store. We verify them before saving and register the order webhook for you.

Reference: official WooCommerce REST API docs ↗

Don't see "REST API" under Advanced? Troubleshooting
  • Older WooCommerce: upgrade to WC 3.4+ — earlier versions had keys elsewhere.
  • Plugin conflict: a security plugin can hide the REST API. Disable it temporarily, or whitelist the WC REST API.
  • Multisite: generate keys on the specific subsite, not the network admin.
  • Permissions: you must be a WP admin (the "Administrator" role) on this site to see the API page.
